* Model
For small swings the period barely depends on the amplitude $\theta_0$:

\[ T \approx 2\pi \sqrt{\frac{L}{g}} \left( 1 + \frac{\theta_0^2}{16} \right) \]

* Analysis
#+begin_src cpp
auto period(double L, double theta0) -> double {
    constexpr double g = 9.81;
    const double t0 = 2.0 * std::numbers::pi * std::sqrt(L / g);
    return t0 * (1.0 + theta0 * theta0 / 16.0);   // => only for small swings
}
