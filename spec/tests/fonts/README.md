# Test-only fonts

`NotoSansDevanagari-Regular.ttf`: Noto Sans Devanagari, Regular, static (also has Latin), from
https://github.com/notofonts/notofonts.github.io (fonts/NotoSansDevanagari/full/ttf). SIL Open Font
License 1.1, see `OFL.txt` (the Noto Project Authors' copy from github.com/google/fonts). Used by the
visual fixture `visual/indic` (`config-indic.toml`) and by calligrus's `calligrus-prose-shaping-test`
(spec 32); not shipped in the apps.
